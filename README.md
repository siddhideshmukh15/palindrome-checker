# Palindrome Checker

A simple **Palindrome Checker** built using Python. This beginner-friendly project checks whether a word or number reads the same forward and backward.

## Features

- Accepts a word or number from the user
- Checks whether it is a palindrome
- Displays the result clearly
- Simple and beginner-friendly

## Technologies Used

- Python
- String slicing
- User input
- `if-else` statements

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the program:

    python palindrome-checker.py

## Concepts Learned

- Taking user input
- Strings
- String slicing
- Conditional statements
- Comparing strings
- Basic Python logic

## Example

    Enter a word or number: tattarrattat
    It is a Palindrome!
